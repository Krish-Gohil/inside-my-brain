# Inside My Brain

Personal operating system / portfolio for Krish Gohil.

Immersive React + Three.js experience with a 3D knowledge constellation on the homepage.

## Stack

- React + TypeScript + Vite
- Three.js via `@react-three/fiber` + `@react-three/drei`
- Framer Motion
- React Router

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
